# BriefVu 外链建设计划 v1

版本：1.0
日期：2026-08-26
周期：90 天
范围：不包含 Reddit；Reddit 由独立运营任务负责。

## 1. 目标与原则

BriefVu 的外链建设不是为了短期堆高域名指标，而是让真实的 custom apparel / screen printing 从业者和软件买家在相关页面发现产品。

90 天目标：

- 获得 12–20 个新的、已索引的相关 referring domains；
- 至少 5 个链接来自印刷、服装装饰、小型店铺运营或 B2B 软件购买场景；
- 至少 4 个链接直接指向指南、用例或示例页，而不全部指向首页；
- 产生第一批可识别的 referral visits 和 paid-pilot applications；
- 建立一套可重复的 prospect、outreach、follow-up 和结果记录流程。

质量优先级：

1. 行业相关性；
2. 页面真实可索引且有读者；
3. 链接所在内容有独立价值；
4. 能带来目标用户或品牌信任；
5. 最后才考虑第三方 DR/DA 指标。

明确不做：

- 批量自动提交 50–700 个目录；
- 购买站群、PBN、低质量 guest post 或“保证 DR”服务；
- 为免费目录在全站 footer 放置强制互链 badge；
- 批量使用完全匹配锚文本；
- 伪造客户数据、测试结果、评价或行业统计；
- 向同一联系人连续追发多封邮件。

## 2. 可传播定位

一句话：

> BriefVu turns messy custom apparel enquiries into verified, quote-ready job specs and drafts only the follow-up questions still needed.

核心差异：

- 位于 Printavo、YoPrint、spreadsheet 之前，是 intake layer，而不是替代完整 shop management software；
- 将提取结果连接到原始 evidence，店员逐项确认；
- 识别 missing、ambiguous 和 conflicting details；
- 合并客户回复，重新计算 quote readiness；
- 不自动报价、不自动联系客户，最终决定仍由店员负责；
- 当前最适合单一产品的 screen printing、embroidery、DTF 和 heat-transfer enquiries。

## 3. 四条外链渠道

### A. 行业媒体与协会

这是最重要的渠道，因为读者与 ICP 高度重合。

| 目标 | 机会 | 优先级 | 当前入口/依据 | 下一动作 |
| --- | --- | --- | --- | --- |
| Screen Printing Magazine | factual product news、workflow article | P0 | 官方接受 vendor press releases，并要求新闻写法、避免夸张宣传 | 在获得 1 个真实 Pilot 或发布可引用 checklist 后投递 |
| Apparelist | expert contribution、workflow article | P0 | 其定位明确包含 apparel decorator 的 business management resources，并有行业 contributor | 给 Content Director 提交非产品推销型选题 |
| PRINTING United Alliance | member supplier directory、community、软件资源 | P1 | 公开目录允许公司说明、capabilities、software 和 website；只有会员可被列出 | 先询价会员成本，确认商业价值后再付费 |
| Screen Printing Magazine Brain Squad | 行业关系和编辑曝光 | 暂缓 | 主要招募 shop owners，不适合产品创始人冒充店主 | 只用于邀请未来 Pilot 店铺参与，不由 BriefVu 直接申请 |

首批媒体选题：

1. **Why Apparel Quotes Break Before Pricing Begins**
   讲 quantity、garment、decoration、locations、artwork、deadline 如何在 intake 阶段造成返工。
2. **The Minimum Information Needed for a Screen-Printing Quote**
   提供独立清单，链接到公开 checklist。
3. **How to Ask Fewer Follow-up Questions on Custom Apparel Enquiries**
   介绍集中澄清、evidence review 和 human approval，不写成产品广告。
4. **What AI Should Not Automate in an Apparel Quote Workflow**
   强调不自动报价、不静默覆盖、不自动发送的安全边界。

### B. 权威软件平台与精选目录

目录只做少量高质量、人工审核、与 B2B 软件购买相关的平台。

| 目标 | 优先级 | 条件 | 计划 |
| --- | --- | --- | --- |
| G2 | P0 | B2B 产品，需研究团队审核分类 | 申请产品 profile；建议类别围绕 quoting/intake/workflow，不宣称完整 ERP |
| Capterra | P0 | 建立 vendor listing | 在产品说明、截图和 support contact 齐备后申请 |
| Product Hunt | P1 | 需要完整 launch 素材；官方要求至少 2 张 gallery images | 等 1–3 个真实 Pilot 反馈或一个明显版本节点后集中发布，不提前消耗 launch |
| AlternativeTo | P1 | 需明确可比较产品 | 以“intake layer”定位，避免声称完整替代 Printavo/YoPrint |
| Micro SaaS Examples | P1 | 人工审核，需要 logo、1200×630 thumbnail 和具体 workflow context | 准备统一 listing kit 后提交 |
| directree | P2 | 免费、founder-verifiable | 可作为早期基础 citation；只在无需强制互链时提交 |

暂不采用任何承诺“保证 DR”或批量代投的服务。免费 listing 如果要求全站 dofollow badge，默认放弃。

### C. 合作伙伴与资源页

比通用目录更可能带来目标用户。Prospect 类型：

- 服务 screen-printing shops 的顾问、教练和 fractional operations specialists；
- 为印花店搭建网站、表单、SEO 或自动化的 agency；
- custom apparel 培训课程、newsletter、podcast 和 YouTube 频道；
- contract decorators、trade printers 和 artwork/vectorization 服务商的资源页；
- Printavo、YoPrint 顾问和 implementation partners；
- 讲解“如何准备 apparel quote”的供应商教育资源。

合作方式按价值排序：

1. 对方资源页收录公开 quote intake checklist；
2. 联合制作“客户询价交接清单”；
3. 由对方审阅并改进 checklist，署名贡献者；
4. 提供不含客户隐私的 workflow teardown；
5. 在真实使用后制作小型 case study；
6. 参加 podcast/newsletter 问答并链接到深层资源页。

首批目标量：建立 30 个 prospect，筛出 12 个高匹配对象，每周联系 3–4 个。

### D. 可引用内容资产

现有最强资产是 quote intake checklist，但要进一步提高“值得被引用”的程度。

| 资产 | 作用 | 前置条件 | 优先级 |
| --- | --- | --- | --- |
| Printable Custom Apparel Quote Intake Checklist | 培训文章和资源页可直接引用 | 将现有指南增强为可打印版本 | P0 |
| Screen Printing vs Embroidery Intake Matrix | 对比不同工艺的必需信息 | 使用现有规则，不加入未经验证的成本结论 | P0 |
| Quote Readiness Self-Assessment | 免费交互工具，输出缺失项 | 可复用现有 deterministic rule engine | P1 |
| Anonymous Intake Benchmark | 原创数据和数字 PR | 至少有足够真实、去内容化样本；不能使用合成流量 | P2 |
| Pilot Case Study | 证明时间/轮次价值 | 取得店铺明确书面许可 | P2 |

没有真实样本前不发布百分比、平均节省时间或“行业 benchmark”。

## 4. 90 天执行节奏

### 第 1–2 周：建立基础资产

- 完成 listing kit：logo、square icon、1200×630 screenshot、60 字符 tagline、50/150/500 字描述、founder bio、support contact；
- 为每个渠道创建独立 UTM，例如 `utm_source=g2&utm_medium=referral&utm_campaign=backlinks_v1`；
- 增强 checklist，使其适合被行业文章直接引用；
- 建立 30 个 niche prospects，记录相关页面、联系人、联系理由和目标深层 URL；
- 提交 G2、Capterra、Micro SaaS Examples 等 3–4 个基础 listing；
- 起草第一篇行业媒体文章，不立即群发。

验收：listing kit 完整；30 个 prospect；至少 3 个已提交状态；所有投放 URL 可追踪。

### 第 3–4 周：首轮定向 outreach

- 每周联系 3–4 个高匹配顾问、agency、newsletter 或资源页维护者；
- 每封邮件只提出一个具体资源和一个具体页面，不发送通用“交换链接”请求；
- 对无回复者 7–10 天后只 follow up 一次；
- 向 Apparelist 提交一个非产品推销型选题；
- 若已有可公开的产品更新或 Pilot 里程碑，准备 Screen Printing Magazine factual press release。

验收：8–12 个个性化 contacts；回复率、正向回复和 live link 分开记录。

### 第 2 月：扩大行业相关链接

- 发布 Screen Printing vs Embroidery Intake Matrix；
- 用新资产联系第二批 12–15 个 prospects；
- 争取 1 篇行业 guest contribution 或 newsletter inclusion；
- 检查所有已上线 listing 是否被索引、链接是否可抓取；
- 评估 PRINTING United Alliance 会员目录成本，不因单纯追求链接购买会员；
- 如果 Product Hunt 素材和真实反馈不足，继续延后 launch。

验收：累计 6–10 个新 referring domains，其中至少 3 个为 niche links。

### 第 3 月：数据驱动与可重复化

- 将有 referral traffic 的渠道升级为长期合作；
- 对无流量、未索引或低质量目录停止投入；
- 有足够真实样本后，规划 privacy-safe benchmark；否则继续用 checklist/matrix 获取链接；
- 有真实 Pilot 且获得许可后发布 case study；
- 条件成熟时执行 Product Hunt launch；
- 复盘 90 天数据，决定扩大 guest content、partners 还是 software review platforms。

验收：累计 12–20 个相关 referring domains，至少 1 个渠道产生合格 Pilot lead 或明确购买者对话。

## 6. Tracking 字段

每个目标记录：

- Prospect / domain
- Channel：industry media / directory / partner / resource page / podcast
- Target page URL
- Relevance reason
- Contact name and public contact route
- BriefVu destination URL
- Suggested anchor/context
- First contact date
- Follow-up date
- Status：researched / ready / contacted / replied / accepted / live / rejected
- Live backlink URL
- Index status
- Referral sessions
- Pilot starts / applications
- Notes（不保存私人或非公开个人信息）

每周只看四个核心数字：

1. 新增高匹配 prospects；
2. 个性化 contacts；
3. live、已索引 referring domains；
4. referral visits 与 Pilot conversions。

## 7. 首轮行动清单

由 Codex 完成：

- 生成统一 listing/outreach 文案；
- 审核并增强 linkable content；
- 为 prospect 做公开资料研究和优先级排序；
- 创建 UTM 规则与 tracking 模板；
- 起草媒体 pitch、guest article 和 press release；
- 定期检查链接、索引和站内转化数据。

由创始人完成或最终确认：

- 提供对外使用的 founder name、support/contact email 和 logo；
- 登录 G2、Capterra、Product Hunt 等第三方账户；
- 批准任何付费会员或付费 listing；
- 发送以本人身份进行的 editorial/partner outreach；
- 批准公开引用任何 Pilot 商店名称、评价或结果。

下一执行批次：先制作 listing kit 与 30 个 niche prospect 清单，再提交首批 3–4 个免费/人工审核平台；不等待 Reddit 运营结果。
