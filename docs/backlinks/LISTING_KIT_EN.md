## Product details

- Product: BriefVu
- Website: https://briefvu.com
- Primary category: Image tools / Graphics utilities
- Audience: Designers, web developers, game creators, and people preparing images for sharing
- Price: Free for the tools described on the website
- Delivery: Browser application; local processing where stated on each tool page
- Account: Not required for these image tools

## Tagline

Private image tools, right in your browser.

## One sentence

BriefVu offers free browser tools to edit, convert, compress, inspect, and prepare images without uploading the files.

## Short description

Crop, resize, remove recognized image metadata, extract color palettes, build favicon packs, arrange sprite sheets, and edit photos or layered PSD files. BriefVu processes supported files on your device and explains each tool’s format and size limits. No account is required.
